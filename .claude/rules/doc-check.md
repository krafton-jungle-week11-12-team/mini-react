# 문서 검수 규칙

문서를 만들거나 고칠 때마다 doc-check 검수는 필수예요. 스킬을 썼는지와 상관없고, `docs/` 밖의 문서(`.claude/` 아래 스킬, 규칙, 템플릿, README)도 포함해요.

1. 결과를 주기 전에 [doc-check](../skills/doc-check/SKILL.md) 절차를 이번에 만들거나 고친 문서 경로를 입력으로 처음부터 끝까지 따라요. 일부 항목만 `grep`으로 보고 "검수 통과"라고 적지 않아요.
2. 이번에 만들거나 고친 문서의 문제는 고치고 다시 검수해요.
3. 검수 결과 표를 결과와 함께 보여 줘요.

코드는 doc-check 대상이 아니에요. 코드 리뷰는 별도 스킬로 해요.
