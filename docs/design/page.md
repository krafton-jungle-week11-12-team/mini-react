## 개요

검증 페이지는 실제 영역과 테스트 영역을 나란히 보여 주고, 로드·Patch·기록 이동 때 엔진 모듈을 순서대로 불러요. 이 문서를 읽으면 화면 구성과 버튼마다 어떤 모듈을 어떤 순서로 부르는지 알고 페이지를 구현할 수 있어요.

## 위치와 흐름

요구사항 4절 "동작 흐름"의 세 흐름을 이 문서가 엮어요.

```text
로드      : 샘플 HTML ─▶ 두 영역 렌더링 ─▶ Virtual DOM 변환 ─▶ State History 첫 기록
Patch     : 테스트 영역 렌더링 ─▶ Virtual DOM 변환 ─▶ Diff ─▶ Patch ─▶ 변경 표시 ─▶ State History 새 기록
기록 이동 : State History 이동 ─▶ 두 영역 복원
```

- 입력을 주는 곳: 사용자(HTML 코드 수정, Patch·뒤로가기·앞으로가기 버튼)
- 출력을 받는 곳: 화면. 엔진 모듈([Virtual DOM 변환](vdom.md), [Diff](diff.md), [Patch](patch.md), [State History](history.md), [변경 표시](change-highlight.md))을 부르는 쪽이에요.

## 설계 결정

| 결정                                                                                  | 이유                                                     | 관련 ADR                              |
| ------------------------------------------------------------------------------------- | -------------------------------------------------------- | ------------------------------------- |
| 테스트 영역은 로드, Patch, 기록 이동 모두 HTML 코드를 파싱한 DOM으로 렌더링한다        | 테스트 영역이 엔진을 거치지 않아 비교 기준이 돼요        | [ADR-004](../adr/ADR-004.md)          |
| HTML 코드의 유효성 검사를 하지 않는다                                                 | 브라우저가 파싱하며 두 영역에 똑같이 보정해요            | [ADR-005](../adr/ADR-005.md)          |
| Patch 버튼 활성화를 판단할 때만 주석을 무시한다. 공백 변경은 변경으로 본다            | 정확성을 먼저 택해요                                     | [ADR-007](../adr/ADR-007.md) (제안됨) |
| 강조 표시는 변경 표시 모듈에 맡긴다                                                   | 변경 표시는 Diff와 분리해요                              | [ADR-008](../adr/ADR-008.md) (제안됨) |

## 검증 방법

- 단위 테스트: Patch 핸들러를 직접 불러 FR-W28을 확인해요.
- 검증 페이지
  - FR-W05, W06: 로드 직후 두 영역의 HTML 코드 문자열과 렌더링 결과가 같은지 확인해요.
  - FR-W10, W25, W26: 수정 전, 되돌린 뒤, 공백만 바꾼 뒤, 주석만 추가한 뒤 Patch 버튼 상태를 확인해요.
  - FR-W19, W20: 테스트 영역의 HTML 코드가 `history[i].html` 원문과 같고, 두 영역의 렌더링 결과가 `history[i].vdom`과 같은지 확인해요.

## 정하지 않은 것

- ADR-007 승인 여부: 승인되면 FR-W25, W26이 바뀌어요. 공백 변경은 Patch 버튼을 켜고, 주석은 버튼 판단에서만 무시해요.
- 뒤로가기, 앞으로가기 때 실제 영역 복원 방식(기록의 상태 전체로 바꿀지, Diff와 Patch를 거칠지): 요구사항 4.3, 6절. ADR 후보예요.
- 주석을 무시하는 비교 함수의 위치(Diff 옵션 또는 별도 함수): [Diff 설계](diff.md)와 함께 정해요.
- Patch 버튼 활성화를 판단하는 시점(입력할 때마다, 일정 시간 입력이 멈췄을 때 등).
- 스크립트 실행 정책: 요구사항 2.2, 7절.
